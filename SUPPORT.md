# Support

Companyware Desktop is currently a development preview without a supported stable
release or guaranteed response time.

- Use GitHub Issues for reproducible defects and bounded feature proposals that
  contain no confidential information.
- Use GitHub Discussions, when enabled, for general development questions.
- Report vulnerabilities privately as described in `SECURITY.md`.
- Keep Companyware Web questions in the Web repository; Desktop and Web have
  separate runtimes and release status.

Before opening an issue, identify the exact commit or release, operating system,
Java version, Derby profile and relevant plugin versions. Remove secrets, internal
hostnames, personal data, invoices and database contents from logs and screenshots.

The documentation entry point is `docs/README.md`. Backup and recovery guidance
is in `docs/derby-backup.md` and `docs/release-process.md`.
