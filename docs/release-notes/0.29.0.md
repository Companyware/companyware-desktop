# Companyware Desktop 0.29.0

Status: **Development Preview**

Companyware Desktop 0.29.0 is the first release produced by the automated
GitHub Windows release path. It is intended for evaluation and plugin/framework
development. Companyware Web remains an independently released Symfony product.

## Highlights

- Java 8/Swing Desktop application with embedded Derby and an optional external
  Derby Network Server profile.
- Versioned public Plugin SDK, deterministic `.cwp` packages and standalone
  HelloWorld-derived plugin starter.
- Trusted-local plugin inspection, installation, activation, update and
  uninstall with dependency and migration checks.
- Localized Companyware shell, theme providers, authentication, permissions,
  audit and recovery foundations.
- Current invoice workflow with controlled templates, PDF and e-invoice output,
  branding, archive and reviewed SMTP delivery.
- Self-contained per-user `Companyware-Setup.exe` with a private Temurin Java 8
  runtime; no separate Java installation is required for the installer path.
- Portable `companyware-desktop.zip` for controlled tests and developer use.

## Installation

1. Download `Companyware-Setup.exe` from this release.
2. Compare its SHA-256 value with `SHA256SUMS.txt`.
3. Run the per-user installer and start **Companyware Desktop** from the Start
   menu.
4. On a new database, sign in with `companyware` / `companyware` and replace the
   initial password immediately when prompted.

Program files are installed below `%LOCALAPPDATA%\Programs\Companyware Desktop`.
The embedded database and installed plugins remain below `%APPDATA%\Companyware`
so program upgrades do not overwrite user data. Back up the complete database
before every upgrade.

## Important limitations

- This is a Development Preview, not a supported stable business release.
- The installer is not yet Authenticode-signed. Windows can therefore display
  **Unknown publisher**. Use only the official GitHub asset and verify its hash.
- Third-party plugins execute as trusted in-process code. Publisher signatures
  and the Store-neutral trust gates are not complete.
- Companyware Desktop and Companyware Web do not share binaries, databases or
  release status.

## Source and evidence

Developers use the immutable `v0.29.0` tag, a 64-bit JDK 8 and the checked-in
Maven Wrapper. `release.json` records version, tag, public commit and asset
hashes; `release-evidence.json` binds the reproducible Source build to the same
commit. Build outputs are release assets and are not committed to Git.
