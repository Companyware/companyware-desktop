# Companyware Desktop 0.29.0-rc.1

Status: **unpublished release candidate**

This is the first release candidate prepared under the Companyware product-family
contract. It contains Companyware Desktop only; Companyware Web is a separate
application and release.

## Highlights

- Product identity is visible as Companyware Desktop in splash, native window
  title, sidebar, login, About information and Windows metadata.
- The public Java Plugin SDK, trusted-local `.cwp` lifecycle, Derby profiles,
  localization, themes, identity/recovery and invoice workflow are documented as
  a standalone Desktop platform.
- GitHub-facing security, support, contribution, issue/PR and read-only CI
  surfaces are prepared without publishing them.
- Java-8 dependencies are moved to the reviewed final Spring Boot 2.7 and
  Hibernate 5.6 baselines; unused legacy libraries and the bundled JRE are removed.
- Release output is versioned, byte-reproducible and accompanied by SHA-256 files,
  an exact dependency inventory and machine-readable release evidence.

## Compatibility

- Requires a 64-bit Java 8 JRE or newer compatible runtime.
- Existing Maven coordinates, Java packages, plugin IDs, API contracts, Derby
  schema identifiers and `Companyware.jar` launcher name remain stable.
- This release candidate does not include or imply a Companyware Web release.

## Evidence and publication

The generated `release-evidence.json` records the exact commit and hashes for
`Companyware.jar`, `companyware-desktop-0.29.0-rc.1.zip` and the dependency
inventory. No GitHub branch, tag or release is changed by preparing this candidate.
Publication still requires explicit approval and the external checks listed in
the security review and release process.
